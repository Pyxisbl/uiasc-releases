# UIASC releases

Update feed and downloads for [UIASC](https://github.com/Pyxisbl), a native macOS app for the `asc` App Store Connect CLI.

- `appcast.xml` is the [Sparkle](https://sparkle-project.org) feed that UIASC reads to check for updates.
- DMGs are attached to the [releases](https://github.com/Pyxisbl/uiasc-releases/releases).

Alpha builds are not notarized yet. macOS will block the first launch; right-click UIASC.app and choose **Open**, or run `xattr -dr com.apple.quarantine /Applications/UIASC.app`.
